# Contributing to OpenGLFW

Thank you for your interest in contributing to OpenGLFW! Since this project is a Swift-based wrapper/interop with C/C++ (inspired by GLFW 3.4), we value high-quality, well-tested code.

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please open an issue on GitHub. Include:
- A clear title.
- Steps to reproduce.
- Environment details (OS, Swift version, etc.).
- Expected vs. Actual behavior.

### Suggesting Enhancements
We welcome ideas for new features or improvements. Please open an issue first to discuss the idea before implementing it.

### Pull Requests
1. Fork the repository.
2. Create a branch for your feature/fix.
3. Ensure your code follows the existing patterns and C-interop conventions.
4. Run any available tests or linting scripts.
5. Submit a PR with a clear description of the changes.

## Coding Standards
- Follow the existing C/C++ coding style in `Sources/`.
- For Swift parts, follow standard Swift API Design Guidelines.
- Keep the codebase clean and avoid unnecessary dependencies.

## Security Policy
Please report security vulnerabilities privately via email (if a contact is provided) or through GitHub's security advisory feature, rather than opening a public issue.
